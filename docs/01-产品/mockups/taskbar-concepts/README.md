# 任务条交互定稿（A2）

最终交互以以下两张图为准：

- `行内详情优化/行内详情-A2-总览.png`：展开、可选信息、完成态总览
- `任务条点击方案/点击色条-A-交互流程.png`：点色段、点箭头、点圆圈的三步流程

## 交互规则

1. 三色任务条按安排数显示红、橙、绿三个比例段；安排包括待办和日程。
2. 锁屏、桌面、通知栏和 App 顶部统一把任务条本身作为入口，直接点击色段切换分组；不另设“查看全部”或独立三标签按钮，当前分组用白色圆环标出。
3. 截止时间固定在任务标题行右侧；点击右侧箭头后，在该任务下方原地展开。
4. 展开区只显示地点、备注等补充信息，不显示提醒提前量。
5. 地点和备注有哪项就显示哪项；两项都没有时，不出现右侧展开箭头。
6. 点击待办或日程左侧圆圈即完成，该行立即消失，同时更新数量和三色任务条；日程圆圈内带日历图标，点标题仍进入日程编辑。
7. 桌面展开时，任务总览卡贴在状态栏下方、从屏幕最上方展开，不悬浮在桌面中部。

## 数据口径

- App 顶部总览把未来 7 天的个人日程与全部未完成待办合并到同一条时间线，按时间计算红 / 橙 / 绿紧急度。
- 日程完成状态按「人 + 日程 + 这一次出现」保存：重复日程只完成被点击的那一次，取消完成也会同步回日历页。
- 这是同屏合并视图，不复制数据；日程和待办仍分别保存，回到页面时两边都会重新拉取。

## 视觉要求

- 标签文字使用深灰 `#4A4C52`，内容使用 `#25262A`，不使用过浅的辅助灰。
- 展开详情不跳转 App，也不切换成新的详情页。
