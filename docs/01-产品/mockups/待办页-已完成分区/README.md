# 待办页：待安排 / 任务 / 已完成

已选定方案 A（纸白三段式），并已按此布局落地到 App 待办页。

## 页面规则

- 从上到下固定为：三色任务条 → 待安排 → 任务 → 已完成。
- 三色任务条放在页面标题下方第一块，作为整个待办页的总览。
- 任意分组为空时，整个标题、计数和内容卡片一起隐藏。
- 全部为空时，三色任务条和各分组一起隐藏，只显示空状态提示和右下角新建按钮。
- 已完成项使用灰色、删除线和实心勾选，和未完成任务拉开层级。
- 三色任务条保留，用于表达紧急 / 临近 / 从容。

## 三个方向

| 方案 | 特点 | 适用性 |
| --- | --- | --- |
| A 纸白三段式 | 留白最多，细边框卡片，接近现有 App 风格 | 推荐，改动最小、层级最清楚 |
| B 柔和分组卡 | 灰底白卡、轻阴影，每个分组更像独立收纳盒 | 分区感更强，但视觉重量略高 |
| C 高对比清单 | 黑色分区线、编号和开放式列表 | 最利落，更像纸质日程本 |

## 空状态

三版文案统一为「目前还没有待办哦」，下面补充「点右下角 ＋，记下第一件事」。

- A：轻量便签轮廓，最克制。
- B：柔和卡片和勾选图标，更温和。
- C：大号圆圈勾选，最有黑白识别度。
