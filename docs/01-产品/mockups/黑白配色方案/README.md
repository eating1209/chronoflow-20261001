# 黑白配色方案

以已确认的「统一新建 · 待办（B 顶部切换）」和「未来安排 · 月份分组（C）」为基准，仅替换颜色，不改布局、文案和交互。全部图片为纯灰度，无米黄或红橙绿残留。

## 先看这两张

- `四版总览.png`：四种方案放在同一张图里对比
- `四版对比-未来安排.png`：未来安排页的横向对比
- `四版对比-待办.png`：统一新建页的横向对比

## 四个方向

| 方案 | 页面底色 | 卡片 | 边界 | 气质 |
| --- | --- | --- | --- | --- |
| A 纸白极简 | `#FFFFFF` | 白色 | 细灰线 | 最克制、最干净 |
| B 雾白低对比 | `#F5F5F5` | 白色 | 浅灰线 | 卡片层次柔和、阅读压力小 |
| C 高对比黑白 | `#FFFFFF` | 白色 | 近黑线 | 分区最清楚，风格最强 |
| D 炭黑深色 | `#0A0A0A` | `#141414` | `#2E2E2E` | 夜间优先、沉浸感最强 |

## 紧急度灰度

| 方案 | 紧急 | 临近 | 从容 |
| --- | --- | --- | --- |
| A | `#161616` | `#6E6E6E` | `#C2C2C2` |
| B | `#202020` | `#7A7A7A` | `#C9C9C9` |
| C | `#000000` | `#595959` | `#A8A8A8` |
| D | `#FFFFFF` | `#8F8F8F` | `#4A4A4A` |

## 单方案预览

每个方案都提供：

- `X-方案名-待办.png`
- `X-方案名-未来安排.png`
