# 备案与变更清单（陶伊婷专用）

> 更新时间：2026-10-26
> 结论先说：**App 备案变更必须做，不能因为应用宝已经上架就跳过。** 应用宝上架只说明应用商店允许分发，不代表工信部 App 备案和公安联网备案的信息已经正确。

## 一、先分清三件事

| 事项 | 当前情况 | 要不要现在做 | 谁提交 | 陶伊婷本人要做什么 |
| --- | --- | --- | --- | --- |
| 工信部 App / ICP 备案变更 | 备案号已有，但 3 个负责人仍是陈诗音，签名 MD5、SDK、功能描述也需核对 | **要做**，先改这个 | 成员 3 黄心用单位账号操作 | 提供身份证、手机号、邮箱；按页面要求实名 / 刷脸 / 签字 |
| 公安联网备案新办 | 尚未办理；App 已上线，属于法定义务 | **要做**，建议在 App 备案变更通过后提交 | 成员 3 黄心填写并跟进 | 法定代表人身份核验、手机接听、必要时签字 / 授权 |
| 公安联网备案变更 | 拿到公安备案号后，主体、负责人、域名、IP、包名、功能等变化才需要 | 目前还没有号，先新办 | 成员 3 黄心跟进 | 只在变更涉及法人信息时配合核验 |

**不要把“每次发版”理解成“每次都要变更”。** 普通版本升级、修 bug、换截图、改商店文案，通常不需要改备案。只有下面这些“登记信息发生变化”才需要：

- 法定代表人 / 主办单位负责人 / App 负责人变化；
- 公司名称、统一社会信用代码、注册地址变化；
- App 名称、包名、域名、服务器 IP、接入服务商变化；
- App 的主要功能描述、内容分类发生实质变化；
- 新增或更换需要备案的第三方 SDK（以最终 APK 和备案页面口径为准）；
- 签名证书变化，且备案页面要求登记签名 MD5 / 证书指纹。

## 二、顺序：先工信部 App 备案变更，再公安备案

公安备案会引用工信部备案号和主体信息。如果先提交公安备案、后改工信部备案，容易出现两边负责人不一致，审核会被打回。

### 第一步：工信部 App / ICP 备案变更

1. **成员 3 黄心**登录阿里云 ICP 代备案管理系统（或工信部政务服务平台），进入已有的 App 备案记录。
2. 选择“**变更备案**”，不要点“新增备案”。
3. 按下面字段逐项核对：

| 字段 | 应填内容 |
| --- | --- |
| 主办单位 | 舟山市时纪云人工智能应用软件有限责任公司 |
| 统一社会信用代码 | `91330901MAKBW9UM38` |
| App 名称 | 时纪流 |
| App 包名 | `com.chronoflow.frontend` |
| App 备案号 | `浙ICP备2026042211号-2A` |
| 域名 | `chronocloud.top` |
| 主办单位负责人 | 陶伊婷 |
| 网站负责人 | 陶伊婷；如管局允许授权，按页面要求上传授权书并填被授权人 |
| App 负责人 | 陶伊婷；同上 |
| 三方 SDK | 按最终 APK 实际内容填；当前客户端重点核对极光推送、高德地图，服务端调用的短信 / 邮件 / 百炼 / 实人认证不要混成内嵌 SDK |
| 功能描述 | 删除“系统日历同步”等当前没有的能力；按“日程管理、组织日程下发、本地提醒、OCR 文字解析”描述 |
| 签名 MD5 / 证书指纹 | 用最终正式包重新核对，不能沿用旧值 |

4. 上传营业执照、陶伊婷身份证正反面、授权书（如果负责人不是法定代表人）、App 截图等页面要求的材料。
5. **陶伊婷本人**完成页面要求的实名核验：一般是身份证信息核对、手机号验证、刷脸，部分情况下需要电子签名。成员 3 不能代替刷脸或签字。
6. 提交后由成员 3 每天看一次状态；管局可能打电话核实，电话要能接通。
7. 审核通过后，保存“变更成功”截图、新的备案详情页和回执，发到项目群。

### 第二步：公安联网备案新办

入口：`https://beian.mps.gov.cn`，用电脑 Chrome 操作。

1. 成员 3 黄心用单位账号注册 / 登录，完成单位实名。
2. 进入“业务办理 → APP 备案 → 新增”。
3. 主体信息按营业执照和变更后的工信部备案填写；负责人填陶伊婷。
4. 材料按 `docs/02-合规/公安联网备案-办理指引.md` 第二节准备：营业执照、法人身份证正反面、安全负责人身份证、工信部 App 备案详情截图、App 首页和关于页截图。
5. 提交后记录受理编号、提交日期、属地网安联系电话；5–20 个工作日属于正常范围。
6. 陶伊婷保持手机畅通。公安来电通常只核实“App 是做什么的、谁负责”，照实回答“日程与待办管理工具，不涉及新闻、直播、社交”。
7. 通过后把公安备案号写进 App 关于页、官网 / 下载页底部、隐私政策页脚和 `docs/02-合规/上架资质核对.md`。

### 第三步：拿到公安备案号后的变更

以后如果法人、负责人、域名、IP、包名或主要功能变化：

1. 先判断是否需要同步改工信部 App 备案；
2. 需要时先完成工信部变更；
3. 再登录公安备案系统，在**原 App 记录**上点“变更”，不要重复新增；
4. 更新对应字段和证明材料，提交后保存回执；
5. 如果只是公安备案号展示位置或普通版本更新，通常不需要变更，按属地网安要求确认即可。

## 三、陶伊婷本人要准备的材料

- 身份证正反面清晰照片（四角完整、不反光）；
- 本人实名手机号、常用邮箱；
- 营业执照照片（向成员 3 要现成的，不需要自己重新办）；
- 需要签字时的电子签名 / 手写签名；
- 授权书（如果由成员 3 代办提交或担任负责人；按备案页面模板填写）。

## 四、哪些事交给成员 3，哪些必须本人做

**成员 3 黄心负责：** 收集材料、登录系统填表、提交、跟踪审核、接普通咨询电话、保存回执、把备案号同步给成员 4 做商店文案、同步给成员 6 更新 App。

**陶伊婷本人必须做：** 身份证实名、刷脸、电子签名、法定代表人授权；审核电话如果明确要求负责人本人接听，也要本人接。

**成员 6 陶伊婷负责的技术部分：** 确认包名、版本号、签名指纹、SDK 清单和功能描述与最终 APK 一致；出 Android 包；把备案号加进 App。不要把所有跑腿和填表都揽到自己身上。

## 五、提交前的 8 项检查

1. 营业执照名称与信用代码逐位一致；
2. 3 个负责人字段不再是陈诗音；
3. App 名称、包名、备案号、域名一致；
4. 功能描述没有写当前不存在的能力；
5. SDK 清单与最终 APK 一致；
6. 签名 MD5 / 指纹来自最终正式包；
7. 法人身份证在有效期内，手机号能接电话；
8. 提交后保存受理编号与截图，不只记在脑子里。
