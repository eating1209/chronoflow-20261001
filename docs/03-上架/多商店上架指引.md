# 多商店上架指引（华为 / 小米 / vivo）· 时纪流

> 目标：把已经在应用宝上架的同一个 App，铺到华为应用市场、小米应用商店、vivo 应用商店。
> 三家材料基本一样，**准备一次能用三遍**；差别在开发者认证方式和审核口味。

## 一、顺序建议

| 顺序 | 商店 | 为什么 | 预计耗时 |
| --- | --- | --- | --- |
| 1 | 华为 | 认证最重（对公打款 1–3 天），先启动 | 认证 1–3 天 + 审核 1–3 天 |
| 2 | 小米 | 认证快，审核快，先把量跑起来 | 1–2 天 |
| 3 | vivo | 与小米接近 | 1–2 天 |

三家可以并行推进，不冲突。

## 四、逐家步骤

### 华为（developer.huawei.com）

1. 注册**企业**账号（用公司公共邮箱/手机号，不要用法人私人号）
2. 企业实名认证：营业执照 + 法人身份证 + 对公账户打款（打款附言必须填页面给的码，金额一分不差）
3. 认证通过 → 创建应用 → **包名必须填 `com.chronoflow.frontend`**（填错不能改）
4. 上传 APK（`arm64-v8a`）→ 填资料：分类「效率/工具」、截图 4 张、隐私政策链接、App 备案号
5. 提交审核（1–3 工作日）
6. 注意：华为在推纯血鸿蒙，目前仍收 Android APK；若哪天要求 `.app` 鸿蒙包，那是另一个工程，需单独评估

### 小米（dev.mi.com）

1. 注册企业开发者 → 实名（营业执照 + 法人 + 对公打款或人脸）
2. 创建应用 → 包名 `com.chronoflow.frontend`
3. 上传 APK + 软著/电子版权证书 + App 备案号
4. 填隐私政策、截图、简介 → 提交（1–2 工作日）
5. 小米会做安全检测，装包后自动扫；有风险项会在审核意见里点名

### vivo（dev.vivo.com.cn）

1. 注册企业开发者 → 实名
2. 创建应用 → 包名 `com.chronoflow.frontend`
3. 上传 APK + 软著 + App 备案号
4. 填资料 → 提交（1–2 工作日）
5. vivo 对「自启动、后台常驻、关联启动」查得严——我们已移除后台定位与自启动类权限，问题不大

## 五、每家都会卡的四件事

1. **包名和签名必须与应用宝完全一致**：包名 `com.chronoflow.frontend`，
   签名 keystore 必须是 `~/keys/chronoflow-release.jks`（MD5 `434b43fe…`）。
   换一把钥匙 = 老用户无法覆盖安装。
2. **versionCode 只能递增**，三家各自独立记录，别搞混。
3. **审核账号**：每家审核前临时开固定验证码，**通过后立刻撤销**（改 `.env` 删两行再重启）。
4. **截图里不能出现真实手机号、身份证、他人姓名**——审核员会截图核对。

## 六、上线之后

- 三个商店各自发版，**不会互相同步**：修一个 bug 要分别传三次包。
- 建议维护一张表：商店 / 当前 versionCode / 上线日期 / 审核人反馈。
- 应用内更新仍然走我们自己的服务器（`/downloads/chronoflow-1.1.0.apk`），
  与商店版本相互独立——商店包被审核卡住时，站内更新照常能发。

## 七、优先级建议

先把**华为**跑通（用户量最大、认证最慢），再上小米、vivo。
三个都上齐大概需要 5–7 个工作日（不含认证等待）。
