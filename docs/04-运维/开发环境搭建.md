# 开发环境搭建（WSL / Ubuntu，从零到能出 APK）

> 适用：本机 `~/chronoflow-20261001-main`。按顺序做，每步都有验收命令。
> 2026-10-18 检查结果：Node 24.22 / npm 11.19 已有；**JDK、Android SDK、Gradle 都没有**。

## 0. 需要多少空间和时间

JDK 约 300MB，Android SDK + NDK + CMake 约 5GB，Gradle 首次下载约 150MB。全程约 30–60 分钟，
主要时间花在下载上（`dl.google.com` 和 `services.gradle.org` 要能访问）。

## 1. 装 JDK 17

```bash
sudo apt update
sudo apt install -y openjdk-17-jdk-headless unzip
java -version          # 期望 17.x
```

写入 shell 配置（**每次开终端都要有 `JAVA_HOME`**）：

```bash
cat >> ~/.bashrc <<'EOF'
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64
export ANDROID_HOME=$HOME/Android/Sdk
export PATH=$PATH:$ANDROID_HOME/cmdline-tools/latest/bin:$ANDROID_HOME/platform-tools
EOF
source ~/.bashrc
```

`keytool` 随 JDK 一起装好，路径是 `$JAVA_HOME/bin/keytool`。

## 2. 装 Android 命令行工具

```bash
mkdir -p ~/Android/Sdk/cmdline-tools
cd /tmp
curl -LO https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip
unzip -q commandlinetools-linux-11076708_latest.zip -d ~/Android/Sdk/cmdline-tools
mv ~/Android/Sdk/cmdline-tools/cmdline-tools ~/Android/Sdk/cmdline-tools/latest
source ~/.bashrc
sdkmanager --version
```

## 3. 先装基础包，再按 prebuild 的要求补版本

```bash
yes | sdkmanager --licenses
sdkmanager "platform-tools"
```

然后拉依赖并生成原生工程（顺便把版本号读出来）：

```bash
cd ~/chronoflow-20261001-main
npm ci
(cd app && npx expo prebuild --platform android --clean)
grep -nE "compileSdk|targetSdk|minSdk|ndkVersion|buildToolsVersion" \
  app/android/build.gradle app/android/app/build.gradle
```

**按 grep 打印的版本安装**（下面的数字只是示例，不要照抄）：

```bash
sdkmanager "platforms;android-36" "build-tools;36.0.0" \
  "ndk;27.1.12297006" "cmake;3.22.1"
```

> NDK 必须与 `ndkVersion` 完全一致，否则会报 “NDK not installed”。
> `cmake` 版本以 `android/app/build.gradle` 或报错提示为准。

## 4. 验收工具链

```bash
java -version
adb version
sdkmanager --list_installed | head -20
```

## 5. 出第一个包

```bash
cd ~/chronoflow-20261001-main
bash scripts/build_apk.sh --prebuild --release --archs=arm64-v8a
```

首次会用 `app/android/gradlew` 下载 Gradle（约 150MB），**10–20 分钟没有输出是正常的**，别中断。
成功时会打印：APK 路径、16KB 页对齐检查、签名指纹。

## 6. 正式签名

见 `docs/04-运维/DEPLOY.md` §4.1.1：生成一次 `~/keys/chronoflow-release.jks`，构建前导出四个
`CHRONOFLOW_KEY*` 变量。`build_apk.sh --release` 缺变量会直接失败，不会用 debug 签名出包。

## 7. 常见问题

| 现象 | 原因 / 处理 |
| --- | --- |
| `Command 'keytool' not found` | JDK 没装，或没用 `$JAVA_HOME/bin/keytool` |
| `SDK location not found` | `ANDROID_HOME` 没生效：`source ~/.bashrc` 后重开终端 |
| `NDK not installed` | 装的 NDK 版本与 `ndkVersion` 不一致，按 §3 重新 grep 后安装 |
| Gradle 下载超时 | 检查 `services.gradle.org` 可访问；必要时在 Windows 侧开代理 |
| 编译被系统杀掉 | 脚本已把 workers/ninja 压到 2；内存 <8GB 时给 WSL 加 swap |
| 桌面没出现 APK 副本 | `/mnt/c/Users/jiang/Desktop` 不存在时脚本会跳过，属正常；可用 `CHRONOFLOW_DESKTOP_DIR` 指定 |
