### 阶段 5：服务器部署

**杭州（生产）**：昨天已迁移完成（数据从北京搬过去，配了 Let's Encrypt 证书），今天**没有动**。

**北京（测试）**：清空数据库 → 上传新 jar → 部署 V26 → 验证邮箱登录生效。

**部署踩的坑**（都是真踩过的）：

1. **`docker compose up --build` 卡死** —— 有两个进程堆叠互相等锁。解决：`ps` 找到 PID 逐个 `kill -9`。
2. **`docker build` 卡 10 分钟无输出** —— 卡在拉基础镜像。解决：**不重新构建**，用现有镜像 + `-v` 挂载新 jar 运行。
3. **`--env-file .env` 变量名不匹配** —— `.env` 里是 `ADMIN_PASSWORD`，容器需要 `ADMIN_BOOTSTRAP_PASSWORD`。compose 会自动映射，`docker run` 不会。**结果：生产自检拒绝启动，容器反复重启**。解决：显式 `-e "ADMIN_BOOTSTRAP_PASSWORD=$ADMIN_PASS"`。
4. **网络名不是 `deploy_default`** —— 是 `chronoflow_default`。用 `docker inspect <容器> --format '{{range $k,$v := .NetworkSettings.Networks}}{{$k}}{{end}}'` 查。

## 三、必须知道的坑

### 1. `~/.m2` 里的旧 jar 会骗你

改了后端代码，但 `mvn test` 跑的却是旧 DTO，报「手机号不能为空」——因为本地仓库缓存着旧版 `chronoflow-auth`。

**解法**：`rm -rf ~/.m2/repository/com/chronoflow && mvn -DskipTests install`

### 2. WSL 的 `/tmp` 会随机消失

今天遇到两次，写好的脚本突然不存在了。**重要脚本别只放 `/tmp`**，或者接受重写。

### 3. 重装 APK 后立刻启动会崩

`AssertionError: Pausing an activity that is not the current activity` —— React Native 的生命周期竞态，**不是代码问题**。再启动一次就正常。

### 4. `adb shell input text` 长文本会被截断

`qatest@example.com` 只输进去 `qatest@exam`。测试时用短输入，或者用 `uiautomator dump` 拿真实坐标后分开输入。

### 5. 接口变更的破坏性

`phone` → `account` 是**破坏性变更**：
- 旧版 App 连新后端 → 400「请输入手机号或邮箱」
- 新版 App 连旧后端 → 400「手机号不能为空」

**部署新后端前必须想清楚客户端怎么办。**
