## 改了什么（4 条）

### 1. iOS 26 / 27 启动闪退：补 UIScene 生命周期

- 现象：在 iOS 26/27 上冷启动立刻闪退，崩溃栈是 `___UIApplicationEvaluateRuntimeIssueForNoSceneLifecycleAdoption_block_invoke`（`EXC_BREAKPOINT`）。
- 原因：RN 0.86.3 + Expo 57 还没有适配 UIScene，`Info.plist` 里也没有 `UIApplicationSceneManifest`。只加 manifest 会变成黑屏，必须同时提供 `SceneDelegate`。
- 改动：新增 `app/plugins/with-ios-scene-delegate.js`（config plugin，`app/ios` 不入库，靠它生成），`app/app.json` 注册该 plugin 并补 `ios.infoPlist.ITSAppUsesNonExemptEncryption=false`。plugin 会把 `AppDelegate.swift` 里建窗与 `startReactNative` 移进 `SceneDelegate`，并把 `openURLContexts` / `continue userActivity` 转发给 `RCTLinkingManager`，避免深链失效。
- 验证：iOS 26.3.1 真机（iPhone 13 Pro）与 iOS 27.1 模拟器都能正常启动到隐私协议页、登录页。

### 2. 登录页被键盘卡死

- 现象：手机号键盘没有回车键、点空白也不收键盘；未勾协议时两个按钮都是灰的，用户既不能收键盘也不能获取验证码，等于卡死。
- 改动：`app/src/modules/identity/screens/LoginScreen.tsx` 外层换成 `KeyboardAvoidingView` + `ScrollView`（`keyboardShouldPersistTaps="handled"`、`keyboardDismissMode="on-drag"`、`automaticallyAdjustKeyboardInsets`），输入框挂 `inputAccessoryViewID`，iOS 上显示「完成」`InputAccessoryView` 调 `Keyboard.dismiss()`；未勾协议且手机号已填满 11 位时给一句提示。
- 验证：`npm run typecheck -w @chronoflow/app`、`npx vitest run test/loginForm.test.ts test/compliance.test.ts` 通过；真机走通「不勾协议 → 收键盘 → 勾协议 → 按钮变亮」。

### 3. iOS 上弹出安卓 APK 更新弹窗

- 现象：iPhone 启动后提示「发现新版本 1.1.0 / 约 86 MB」，点「立即更新」又说不支持。
- 原因：`AppUpdater` 文件头注释写了「只在 Android 生效」，但 `check()` 没有平台守卫，服务端 `app-release` 下发的是安卓 APK 信息。
- 改动：`app/src/modules/notifications/screens/AppUpdater.tsx` 的 `check()` 开头加 `if (Platform.OS !== 'android')` 早退（手动检查时提示走 App Store 更新），渲染层再加一层 `Platform.OS === 'android'` 兜底。
- 验证：真机重启后不再出现该弹窗；审核口径上也不会被判「引导用户下载安装包」。

### 4. OCR 文本解析日期偏移一天（后端）

- 现象：2026-11-03（周二）说「本周四下午 3:30」，解析成 11-06（周五）。
- 原因：提示词只注入日期、没有星期，模型自己心算星期几，`本周X` 常偏一天。
- 改动：`backend-java/chronoflow-agent/.../service/EventDateGuard.java`（新增，按 14 天对照表纠正星期，只改日期不动时刻，多星期歧义时保留原值并告警）、`AgentTextParseService.java`（注入「今天 + 星期」与 `{{date_table}}`）；`backend-python/app/services/event_date_guard.py` 与 `vision_text.py` 同逻辑对齐；两份 `vision-prompt.md` **逐字节相同**（有测试钉住），新增「日期只查表，不做心算」段。
- 验证：新增 `EventDateGuardTest.java` 与 Python 4 个用例；bug 报告里的 11 条用例逐条通过（周四 11-06→11-05、本周二 11-05→11-03、本周三 11-05→11-04、本周五 11-07→11-06）；CI 四个 job 全绿。

## 出包注意（本次未打包上传）

- `expo.ios.buildNumber` 必须大于 ASC 上已有值（现有 `1.1.0 (1)`）。
- bundleId 要与 ASC 里「时纪流」那条 App 记录一致（旧记录是 `com.synji.chronoflow`），否则上传会被拒。
- 改过 `app.json` 后要重跑 `npx expo prebuild --platform ios --no-install`，否则 `app/ios` 里的 scene 补丁不会更新。
- `pod install` 需要三个环境变量（本机验证过）：`PATH` 指向 node 24、`SSL_CERT_FILE` 指向 Homebrew ca-certificates、`ENTERPRISE_REPOSITORY=https://maven.aliyun.com/repository/central`。
