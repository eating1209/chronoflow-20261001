## ⚠️ `legal/` 为什么没归档进 02-合规

这五个文件是**后端打包的输入**：`chronoflow-bootstrap/pom.xml` 在构建时把 `docs/legal/*.md`
复制进 jar，由 `/api/v1/legal/*` 直接渲染成网页。挪动会同时改到 Java 构建、合规检查脚本
（`scripts/check_compliance.py`）和部署脚本，属于「碰代码」，所以原地保留。

想改隐私政策 → 直接改 `docs/legal/*.md` → `bash scripts/deploy_backend.sh`。

## 命名约定

- 日期类文档用 `主题-YYYY-MM-DD.md`（如 `六人分工-2026-10-24.md`）
- 一次性的会议/评审记录放 `01-产品/`，不要散在根目录
- 新文档先问「给谁看」，再决定放哪个目录；拿不准就放 `01-产品/`
